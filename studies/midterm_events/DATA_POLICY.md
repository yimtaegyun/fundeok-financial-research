# 데이터와 공개 범위

원본 가격·팩터·기관 보고서의 저작권이나 재배포 권한이 자동으로 이전되지 않는다. 이번 배포 ZIP에는 원본 ZIP/CSV/HTML, SQLite 데이터베이스, 타 블로거의 이미지·전문을 넣지 않는다. 다운로드 경로·해시, 우리가 작성한 코드, 집계·검증 결과와 자체 그래프만 포함한다.

French 원자료는 원문에 Fama/French의 저작권 표시가 있는 공개 연구용 다운로드다. 코드가 공식 파일을 받아 로컬에서 실행하며 원본 배포를 하지 않는다. FRED에 실린 S&P 데이터 역시 제3자 권리가 존재한다. 사용자는 이후 상업적 이용·원자료 제공 시 제공처 조건을 별도로 확인해야 한다. 이 자료를 수익화 사이트의 가격 피드로 제공할 권한은 확인하지 않았다.

초기에 접근 가능성을 시험한 Yahoo 응답은 재배포·자동 접근 제한을 확인한 뒤 분석 입력에서 제외했다. 분석·차트·제공 코드에 사용하지 않았고 ZIP에도 포함하지 않는다. Yahoo Finance 도움말: https://help.yahoo.com/kb/SLN2310.html

블로거 5인의 공개 HTML·이미지는 구조 측정과 내부 시각 확인에만 사용했다. 콘텐츠·이미지를 복사해 제공하지 않는다. 측정값과 원문 링크, 자체 설명만 남겼다. 측정이 검색 순위의 원인을 입증하지는 않는다.

회사 공시는 재무 사실을 출처·단위·분기와 함께 발췌해 계산했다. Microsoft 분기 현금흐름의 단순 차이는 회사 전체 수치로, AI 부문의 독립 수익률이나 총 설비투자와 다르다. 분기 EPS를 네 배해 현재 PER를 산출하지 않았다.

원자료는 수정될 수 있다. 실제 당시 공개 빈티지를 모두 복원한 백테스트가 아니다. 해시는 실행 스냅샷을 식별하며 데이터 이용 허가 자체를 증명하지는 않는다.
