# 장기금리 데이터 파이프라인 — 2026-10-22 연구

기존 Treasury·Kim–Wright 데이터 수집, 검증, 전처리와 AR(1) 계산 준비 코드를 보존했다. `archive_results/`는 당시 저장한 결과다. 현재 실행에서 전체 수집·모형을 다시 실행한 결과로 표시하지 않는다. AR(1)은 실행 점검용이며, 저장된 테스트 결과에서 0변화 기준 예측보다 우수하지 않았다.

이번 공개 사본은 데이터 파싱 보호 검사가 선택적 회귀 라이브러리 없이 실행되도록 `statsmodels`를 분석 함수 안에서 불러온다. 수집·정제·회귀 계산식은 유지했다.

저장소 루트에서 보호 검사:

```bash
python -m unittest discover -s studies/macro_foundations/tests -v
```

전체 연구 재수집에는 이 폴더의 `requirements.txt`를 별도 환경에 설치하고 `python src/pipeline.py`를 실행한다. 기준일은 2026-10-22에 고정돼 있다. 이 명령은 정부 서버에 접근하며 원본·산출물을 로컬 `artifacts/`에 생성한다. 과거 스냅샷 전체와 월별 확장 자료는 이번 공개 사본에 포함하지 않았다. `scripts/expand_macro.py`는 기존 실행의 원본 폴더가 있을 때 사용하는 후속 코드다.

원자료를 새로 받으면 과거 수정으로 저장된 결과와 달라질 수 있다. 이 연구를 당시 실시간 투자 성과 또는 주식 백테스트로 제시하지 않는다.
