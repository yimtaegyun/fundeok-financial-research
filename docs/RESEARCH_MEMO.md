# PCE 연구: 질문·계산·검증 범위

기준 발표는 2026-10-29의 미국 9월 개인소득·소비 보고서다. 발표값, 지난달 최초 발표와 수정값, 최근 물가 속도를 같은 단위로 대조하는 기술 연구다.

1. 월별 수준 자료를 날짜와 계열 ID로 정규화하고 유일 키를 검사한다.
2. SQL `LAG`로 전월·전년 변화와 3·6개월 복리 연율을 계산한다.
3. Python `shift`로 독립 계산해 SQL과 수치 오차 1e-10 이내인지 대조한다.
4. 이미 비율인 저축률은 퍼센트포인트 차이로 다룬다.
5. 원래 발표와 수정 발표를 별도 빈티지 행으로 보존한다.
6. 명목·실질금리를 공통 관측일로 맞추고 결측을 보간하지 않는다.

정부 발표 반올림 값과 원자료의 정밀 계산을 구분한다. 근원 물가 3개월 연율은 최근 속도를 환산한 값이며 미래 물가 예측이 아니다. 단일 미래 현금흐름의 할인율 민감도는 실제 주가 모형이 아니다.

2026-10-30 복원 실행에서 데이터 검사 39개, Notebook 코드 셀 6개가 통과했다. 산출 CSV 7개·차트 5개·원자료 CSV 2개·결과 JSON 1개, 총 15개의 SHA-256이 원래 저장본과 일치했다. 정확한 파일 목록과 범위는 `outputs/restoration_verification.json`을 따른다.

이번 연구는 수익률 예측, 인과효과, 매매 백테스트, 실제 주문을 수행하지 않았다. 미래 시점 연구에는 당시 공개 빈티지·발표 시각·컨센서스·가격·비용을 별도로 확보해야 한다.
