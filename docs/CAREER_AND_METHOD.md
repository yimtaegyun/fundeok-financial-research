# 직접 설명할 수 있는 분석 역량

이 저장소는 원자료 정의·SQL 추출·Python 검산·재현 가능한 실행을 보여주는 금융 데이터 포트폴리오다. 코드와 문서 작성에 AI를 활용했으며, 사용자는 실제 코드를 이해하고 재실행한 범위를 자신의 말로 설명한다.

| 역량 | 확인할 파일 | 설명할 핵심 |
| --- | --- | --- |
| 데이터 엔지니어링 | `collect_data.py` | HTML 오응답 거부, 원본 해시, 관측일과 수집일 |
| SQL | `analysis.sql` | 유일 키, LAG, 빈티지 조인, 공통 날짜 |
| 독립 검산 | `run_analysis.py` | SQL과 별도 Python 계산의 일치 |
| 시각화 | `figures/` | 같은 단위·기간·자료 빈티지, 한글 글꼴 |
| 연구 검증 | `outputs/qa_results.json` | 실제 검사 결과와 검증하지 않은 범위 |
| 재현 | `analysis_notebook.ipynb` | 순차 CPython 실행과 Jupyter 커널 검증의 차이 |

면접 전 직접 해볼 일은 6월·9월 근원 지수로 3개월 연율을 다시 계산하기, 8월 최초 발표와 수정치를 구분하기, 저축률에 퍼센트포인트를 쓰는 이유와 할인율 민감도의 한계를 설명하기다.
