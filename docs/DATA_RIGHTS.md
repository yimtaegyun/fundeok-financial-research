# 출처·공개 범위

확인일: 2026-10-29. 재배포할 자료와 링크로만 제공할 자료를 구분한다. 이 문서는 타인의 콘텐츠를 임의로 재허가하지 않는다.

| 자료 | 이번 처리 |
| --- | --- |
| BEA·연준·FEC 정부 발표와 정부 수치 | 출처·수집 시각·해시와 함께 포함. 정부 기관의 로고나 지지를 우리 브랜드로 사용하지 않음 |
| FRED를 통해 받은 BEA 계열, DGS2·DGS10·DFII10 | 계열 출처와 FRED를 표시. Public Domain: Citation Requested 계열. 전체 서비스를 복제하지 않고 필요한 소수 계열만 사용 |
| 10년 손익분기율 | 정부 명목·실질금리의 차이로 직접 계산. FRED T10YIE는 공개 페이지의 참고 비교 링크이며 원본 계열 다운로드는 최종 프로젝트에 포함하지 않음 |
| CME·Econoday 조사값 | 필요한 예상치와 원문 링크·확인 시각만 기록. 기사 본문·사진은 포함하지 않음 |
| Reuters/Ipsos 여론조사 | 필요한 수치·대상·조사일·방법론 링크와 직접 작성한 그래프만 포함. PDF·사진·기사 전문 재배포 안 함 |
| 다른 블로거·크리에이터 | 링크와 제한된 형식 관찰만 제공. 원문·영상·자막·사진을 파일이나 공개 저장소에 복사하지 않음 |
| NanumGothic 글꼴 | SIL Open Font License 원문을 `assets/FONT_LICENSE.txt`에 포함 |
| 표지 | 내장 이미지 생성으로 이번 프로젝트를 위해 제작. 프롬프트 기록은 전체 제작 패키지에 포함 |
| 분석 그래프·인스타 카드 | 직접 작성한 코드와 수치로 제작. 원본 제공자의 차트를 잘라 쓰지 않음 |

[FRED 이용 조건](https://fred.stlouisfed.org/legal/)은 Public Domain: Citation Requested와 Copyrighted: Citation Required의 표시·인용 조건을 구분한다. 상업적 보고서 사용과 원본 데이터 재배포는 동일한 허가로 가정하지 않는다. 향후 유료 데이터·가격·지수·Finviz·TradingView 자료를 추가할 때는 해당 자료의 조건을 별도 확인한다.

이번 GitHub용 묶음에는 계정 정보·접근 토큰·쿠키·전체 인터뷰 자막·민간 보고서 원문·최초 네 계열 검사용 다운로드를 포함하지 않는다. 정부 공공 데이터와 인용을 보존한 분석 결과를 중심으로 구성했다.
