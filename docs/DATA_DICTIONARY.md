월별 원자료는 날짜당 한 행, SQL 적재는 `(date, series_id)`를 유일 키로 한다. 최초 발표와 수정 발표는 `metric, period, unit, published_at, value, source_file`로 구분한다. 발표일과 관측월을 혼동하지 않는다.

정부 발표의 소수 첫째 자리 수치와 지수 수준에서 재계산한 정밀 수치는 정밀도가 다르다. 예를 들어 근원 전월 0.3165%는 공식 표시 0.3%와 일치한다. 표·제목은 공식 정밀도, 계산 설명은 필요한 자릿수만 사용한다.

수정계열은 과거 실시간 빈티지가 아니다. 과거의 발표 시점에 이 값이 알려져 있었다고 가정하지 않는다. 휴일·미공표 값은 결측이며 0으로 대체하지 않는다. 일간 금리의 최신 공통일은 2026-10-27이다.
